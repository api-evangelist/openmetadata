OpenMetadata is an open-source data catalog and metadata platform providing a comprehensive REST API for managing tables, dashboards, pipelines, data quality, lineage, and governance policies. It serves as an open context layer for data and AI, unifying technical metadata, business semantics, and organizational memory into a unified graph for both human and AI decision-making.

**Areas:** Data Catalog · Metadata · Data Governance · Data Lineage · Data Quality · Open Source · Data Discovery · Data Observability

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for OpenMetadata: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
